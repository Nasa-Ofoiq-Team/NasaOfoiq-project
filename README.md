# 🌿 Al-Nasariya Agricultural Advisory Tool | NASA Space Apps Challenge 2026

An intelligent, data-driven agricultural decision-support web platform designed for farmers and decision-makers in the **Al-Nasariya** region. Built for the **NASA Space Apps Challenge 2026**.

---

## 🚀 Live Demo
🌐 **[View Live Web Application](https://Nasa-Ofoiq-Team.github.io/NasaOfoiq-project/)**

---

## ✨ Features & Functionalities
- 🗺️ **Interactive Regional Map:** Real-time visualization using Leaflet JS.
- 📊 **Agricultural Analytics:** Visual data representations powered by Chart.js.
- 🤖 **AI Agricultural Assistant:** Integrated conversational tool providing real-time local crop and soil recommendations.
- 🎨 **Modern & Responsive UI:** Styled with Tailwind CSS and FontAwesome icons.

---

## 🛠️ Tech Stack & Dependencies
- **HTML5 / CSS3 / JavaScript (ES6+)**
- **Tailwind CSS** (Styling framework)
- **Chart.js** (Data visualization)
- **Leaflet.js** (Interactive mapping)
- **FontAwesome** (Icons)
